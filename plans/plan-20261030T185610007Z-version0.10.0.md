## B01 - Board names (Patch)

## B02 - Click cards to edit on Windows (Minor)

Remove the task edit icon and open its editor by clicking the card, retaining independent completion/delete targets and pending-operation locks. Android retains its existing interaction.

<!-- md-block {"id":"B03","dependsOn":[]} -->
## B03 - Reliable Enter submission (Patch)

Enabled task forms submit with Enter after date/time pickers and other non-description controls. Description Enter remains a newline; Windows Ctrl+Enter retains submission. Picker confirmation must never accidentally submit its parent form. Unchanged/invalid/pending forms remain guarded.

<!-- md-block {"id":"B04","dependsOn":["B03"]} -->
## B04 - Expanded description (Minor)

Add an expand button to new/edit task descriptions on both platforms. Open a description dialog with the same dimensions, rounded shape and spacing as the task form, containing Back, the current task title as noneditable text, and the description field. Retain the same draft, input limit and other task fields. Back/Escape returns without submitting or unexpectedly reopening the keyboard.

The user directly clarified this design on 2026-10-31 after reviewing the first implementation: use the form's frame rather than a fullscreen page; align the smaller expand control with the Subject dropdown and use consistent existing colors. This instruction authorizes the refinement. The description dialog measures the full form content and inherits the existing dialog theme and live size constraints.

The user subsequently reported expansion while the Android keyboard is open, from either the title or description. Native reproduction showed the expanded dialog retaining the reduced viewport height after keyboard dismissal, exposing the original form behind it. Measure the full scroll content instead; the dialog's live constraints handle keyboard opening/closing. Eight regression cases reproduce the failure before the fix and pass afterward across new/edit, title/description focus and both platforms. Preserve text and return without restoring input focus.
